# imageseq_cmd
Unity Recorderで出力したImage Sequenceをffmpegでmp4にしたくて作りました。
大したことしてないけど作業効率上がった気がするのでリポジトリ化

## 使用方法
ffmpegの導入が必要です。
https://www.ffmpeg.org/

ffmpegのパスを通す、またはffmpeg.exeと同じディレクトリ内にimageseq.batを設置して使用します。
実行するとディレクトリを聞かれるので、連番画像が入ったディレクトリを指定してください。

Unity Recorder側で特殊な設定したかどうか覚えていないので設定のキャプチャだけ共有。
